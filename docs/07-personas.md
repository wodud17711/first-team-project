## 🐣 페르소나 1 — 초보 견주 김민지

> 💬 **"처음이라 뭐든 조심스러워요. 확실한 가이드가 필요해요."**

### 기본 정보
| 항목 | 내용 |
| --- | --- |
| 이름 | 김민지 |
| 나이 | 28세 |
| 직업 | 직장인 (가끔 재택근무) |
| 반려견 | 코코 · 말티즈 · 1살 · 단모 소형견 |
| 거주 | 서울 마포구 (빌라) |
| 반려 경력 | 1년 미만 (첫 반려견) |
| 기술 친숙도 | 높음 (앱 사용 능숙, 정보 검색 적극적) |

### 😟 고민
- "이 날씨에 코코 데리고 나가도 되나?"
- "우리 강아지한테 어떤 사료가 좋지?"
- "산책 시간·횟수가 적당한 건지 모르겠다"
- 정보를 찾아도 출처가 제각각이라 뭘 믿어야 할지 혼란

### 📅 하루 일과
- **07:00** 기상 → 가벼운 아침 산책 20분
- **09:00** 출근 → 점심시간에 펫 관련 앱·커뮤니티 확인
- **19:00** 귀가 → 저녁 산책 30분
- **22:00** 코코 사진 정리, 다음날 날씨 확인

### 💬 앱에 바라는 점
- **명확한 가이드** — "오늘 산책 OK/주의/위험"을 한눈에
- 사진으로 산책 추억 기록
- 초보도 이해할 수 있는 쉬운 설명

### ✅ 우리 서비스가 해결하는 것
- **AI 산책 위험도 진단** → "오늘 나가도 되나?" 즉시 해결 *(MVP)*
- **준비물 추천** → 강수 예보 시 우산 등 안내 *(MVP)*
- **커뮤니티 사료·간식 카테고리** → 검증된 정보 수집 *(MVP)*
- **AI Q&A** → 견종별 궁금증 해소 *(Phase 2)*

### 🎯 주로 쓰는 기능
`홈(산책 점수)` · `산책 기록` · `커뮤니티(사료·간식)` · `반려견 프로필`

## 🐕 페르소나 2 — 일반 견주 김대원

> 💬 **"우리 탱구 행동, 같은 고민 가진 사람이랑 얘기하고 싶어요."**

### 기본 정보
| 항목 | 내용 |
| --- | --- |
| 이름 | 김대원 |
| 나이 | 27세 |
| 직업 | 애견미용사 |
| 반려견 | 탱구 · 토이 푸들 · 6살 · 장모 소형견 |
| 거주 | 부산 덕천동 (아파트) |
| 반려 경력 | 5년+ (어느 정도 지식 보유) |
| 기술 친숙도 | 보통 (필요한 앱만 사용) |

### 😟 고민
- "강아지가 하는 행동에 대해 자세히 물어볼 곳이 없다"
- "분리불안 대응책을 찾기가 어렵다"
- 일반 정보는 알지만, **우리 탱구의 구체적 상황**에 맞는 조언이 부족
- 같은 견종·같은 행동을 겪는 보호자와 경험을 나누고 싶음

### 📅 하루 일과
- **09:00** 출근 (애견미용샵) → 점심시간에 펫 앱·커뮤니티 확인
- **19:00** 귀가 → 컨디션에 따라 저녁 산책 30분
- 주말 → 탱구와 시간 보내며 행동 관찰

### 💬 앱에 바라는 점
- **같은 견종·같은 행동을 하는 강아지의 커뮤니티**
- 행동 문제(분리불안 등)에 대한 경험 공유
- 단순 정보가 아닌 "진짜 겪어본" 보호자의 이야기

### ✅ 우리 서비스가 해결하는 것
- **커뮤니티 (견종별·행동 주제)** → 비슷한 고민 공유 *(MVP)*
- **댓글·좋아요·@멘션** → 답변 받는 경험 *(MVP)*
- **AI Q&A** → 행동 문제 1차 상담 *(Phase 2)*
- **1:1 채팅** → 같은 고민 보호자와 직접 소통 *(Phase 2)*

### 🎯 주로 쓰는 기능
`커뮤니티(반려견 자랑·산책 메이트)` · `댓글/좋아요` · `AI Q&A`

## 🦮 페르소나 3 — 액티브 견주 임재영

> 💬 **"찹츄랑 같이 뛸 곳, 적절한 운동량을 알고 싶어요."**

### 기본 정보
| 항목 | 내용 |
| --- | --- |
| 이름 | 임재영 |
| 나이 | 30세 |
| 직업 | 조리사 |
| 반려견 | 찹츄 · 골든리트리버 · 4살 · 대형견 |
| 거주 | 부산 명지동 (아파트) |
| 반려 경력 | 4년 (활동적인 반려 생활) |
| 기술 친숙도 | 높음 (SNS 활발, 기록·공유 즐김) |

### 😟 고민
- "주변에서 반려견과 같이 뛰거나 놀 만한 곳을 찾고 싶다"
- "어느 정도의 산책·놀이가 대형견의 적절한 운동량인지 알고 싶다"
- 대형견 특성상 운동량이 부족하면 스트레스·건강 문제 우려
- 산책·러닝 기록을 SNS에 공유하고 싶음

### 📅 하루 일과
- **출근** (조리사) → 바쁜 근무
- **19:00** 귀가 → 매일 저녁 산책 30분 ~ 1시간 (러닝 포함)
- 주말 → 찹츄와 공원·강변 등 장거리 활동

### 💬 앱에 바라는 점
- **대형견을 키울 때 필요한 정보** (운동량·건강 관리)
- 함께 뛸 수 있는 산책로·코스 정보
- **SNS에 올릴 수 있는** 강아지와 함께한 시간들

### ✅ 우리 서비스가 해결하는 것
- **위치 기반 산책로 추천 (난이도별)** → 함께 뛸 곳 발견 *(Phase 2)*
- **활동량 가이드** → 견종·체중 기반 적정 운동량 *(MVP - 위험도 진단에 포함)*
- **러닝 모드 (시간 측정·랭킹)** → 운동 기록·경쟁 *(Phase 2)*
- **산책 기록 + 사진** → SNS 공유용 콘텐츠 *(MVP)*

### 🎯 주로 쓰는 기능
`산책 기록(러닝)` · `산책로 추천` · `통계` · `커뮤니티(산책로 후기)`

## 🚫 비타겟 사용자

다음 사용자는 본 서비스의 주요 타겟이 아닙니다 (배제하지는 않음):

- **반려견 미보유자**: 일반 정보 조회는 가능하나 핵심 기능 사용 불가
- **전문 훈련사**: 별도 전문 도구가 필요
- **반려견 미용·호텔 업체**: B2B 서비스 영역

## 📌 페르소나 활용

이 페르소나는 다음 의사결정 시 기준으로 활용합니다:

- **기능 우선순위 결정**: 어느 페르소나에게 가장 임팩트가 큰가?
- **UI/UX 설계**: 김민지(초보)도 쉽게 이해할 수 있는가?
- **카피라이팅**: 페르소나가 공감할 톤앤매너인가?
- **마케팅**: 어떤 채널·메시지가 적합한가?
