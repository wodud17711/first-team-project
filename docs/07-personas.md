# 07. 사용자 페르소나

본 서비스의 주요 사용자 그룹을 페르소나로 정의합니다.

> ⚠️ 본 페르소나는 초안이며, 사용자 인터뷰 및 설문을 통해 보완 예정입니다.

---

## 🎯 페르소나 1: 초보 견주 김민지

### 기본 정보
- **나이/직업**: 28세 / 직장인 (사무직)
- **거주 형태**: 1인 가구, 오피스텔
- **반려견**: 2살 포메라니안 (소형견, 장모, 3kg)
- **반려견 이름**: 초코

### 🐕 반려견 관련 상황
- 첫 반려견을 입양한 지 6개월
- 강아지에 대한 지식이 부족함
- 인터넷에서 정보를 찾아도 무엇이 맞는지 판단 어려움

### 😟 페인 포인트
- **"오늘 너무 더운데 산책해도 될까?"** — 매번 고민하지만 명확한 기준이 없음
- 발바닥 화상 같은 위험을 뉴스로만 접해서 막연한 불안
- 사료/간식/병원 정보 찾기 힘듦 (블로그마다 정보가 다름)
- 비슷한 견주 친구가 없어 물어볼 곳이 없음

### 🎯 니즈
- **명확한 가이드**: "오늘은 안전해요" 같은 직접적인 안내
- **안심할 수 있는 근거**: 왜 안전한지/위험한지 설명
- **신뢰할 수 있는 정보**: 검증된 사료, 병원 정보

### 📱 사용 시나리오
1. 퇴근 후 저녁 7시, 산책 나가기 전 앱을 열어 위험도 확인
2. "오늘은 18:00~20:00이 적절해요" 안내를 보고 안심
3. 산책 후 기록 남기고 "잘했어요!" 알림 받음
4. 주말에 커뮤니티에서 포메라니안 사료 추천 글 읽음

### 💎 본 서비스에서 얻는 가치
- 산책 의사결정의 불확실성 해소
- 초보 견주로서의 자신감
- 정보 접근성 향상

## 🎯 페르소나 2: 액티브 견주 박지훈

### 기본 정보
- **나이/직업**: 32세 / 프리랜서 (디자이너)
- **거주 형태**: 부모님과 거주, 단독주택
- **반려견**: 4살 보더콜리 (대형견, 중간 털, 18kg)
- **반려견 이름**: 루키

### 🐕 반려견 관련 상황
- 반려견 키운 지 4년차, 어느 정도 베테랑
- 운동을 좋아해서 강아지와 함께 러닝/등산 즐김
- SNS에 산책 사진 자주 올림

### 😟 페인 포인트
- 활동량 많은 견종이라 매일 충분히 산책시키고 싶지만 좋은 산책로를 모름
- 같은 동네 견주들과 정보 교환할 곳이 없음
- 산책 기록을 남기고 싶은데 사람용 운동 앱은 강아지에 안 맞음
- 한여름·한겨울 무리한 산책으로 강아지가 힘들어한 경험 있음

### 🎯 니즈
- **산책로 추천**: 새로운 코스 발굴
- **기록·통계**: 얼마나 활동했는지 데이터로 확인
- **커뮤니티**: 비슷한 라이프스타일 견주들과 교류
- **위험 경고**: 무리한 활동 방지

### 📱 사용 시나리오
1. 주말 아침 산책 전 위험도 확인 → "오전 10시 전 추천"
2. 산책 시작 버튼 누르고 러닝 시작 → 종료 후 기록 자동 저장
3. 주간 통계 확인 — "이번 주 15km 달성!"
4. 커뮤니티에 좋은 산책로 후기 작성
5. "동반 산책 모집" 게시판에 글 올려서 동네 견주와 만남

### 💎 본 서비스에서 얻는 가치
- 산책 활동의 정량화 (성취감)
- 새로운 산책로 발견
- 같은 관심사 견주와의 네트워킹

## 🎯 페르소나 3: 고령견 보호자 이수연 (선택)

### 기본 정보
- **나이/직업**: 45세 / 주부
- **거주 형태**: 가족과 거주, 아파트
- **반려견**: 12살 시츄 (소형견, 장모, 7kg)
- **반려견 이름**: 봉봉
- **건강 이슈**: 관절염, 심장 문제

### 🐕 반려견 관련 상황
- 노견 케어 경험이 길지만, 갈수록 건강 관리가 어려워짐
- 무리한 산책은 위험, 그렇다고 안 하면 근육이 약해짐
- 주치의 병원과 지속적으로 소통 중

### 😟 페인 포인트
- 노견에게 맞는 산책 시간·강도 판단이 어려움
- 날씨 변화에 매우 민감함 (관절염)
- 비슷한 처지의 노견 보호자 정보가 부족
- 일반적인 가이드는 건강한 강아지 기준이라 도움이 안 됨

### 🎯 니즈
- **노견 특화 가이드**: 건강상태를 반영한 맞춤 추천
- **부드러운 산책 코스**: 평지, 그늘 위주
- **노견 보호자 커뮤니티**: 비슷한 상황의 사람들과 공감

### 📱 사용 시나리오
1. 매일 아침 위험도 확인 — 건강상태 반영된 점수
2. "오늘은 짧게 30분만, 평지로 추천드려요"
3. 산책 후 강아지 컨디션 피드백 기록
4. 노견 보호자 커뮤니티에서 비슷한 고민 공유

### 💎 본 서비스에서 얻는 가치
- 노견 케어의 막막함 해소
- 건강 관리의 객관적 지표
- 정서적 지지

## 🚫 비타겟 사용자

다음 사용자는 본 서비스의 주요 타겟이 아닙니다 (배제하지는 않음):

- **반려견 미보유자**: 일반 정보 조회는 가능하나 핵심 기능 사용 불가
- **전문 훈련사**: 별도 전문 도구가 필요
- **반려견 미용·호텔 업체**: B2B 서비스 영역

이 페르소나는 다음 의사결정 시 기준으로 활용합니다:
