# 08. 산책 위험도 룰베이스

본 서비스의 핵심 AI 기능인 **산책 위험도 측정 룰베이스 모델** 명세입니다.

> 💡 초기 버전(v1)은 규칙 기반(Rule-based)으로 시작하고, 데이터가 축적되면 ML 모델로 확장 예정입니다.

---

## 🎯 목표

다음을 종합하여 **0~100점의 산책 위험도 점수**를 산출합니다:

1. **날씨 데이터** (기상청, 에어코리아)
2. **반려견 특성** (견종, 나이, 체중, 털 길이, 건강상태)
3. **시간대 정보** (오전/오후/저녁/심야)

출력:
- 점수 (0~100)
- 등급 (안전 / 주의 / 위험)
- 위험 사유 리스트
- 추천 시간대

---

## 📊 위험 요소 정의

### 1. 날씨 변수

| 변수 | 출처 | 단위 | 설명 |
| --- | --- | --- | --- |
| 기온 | 기상청 단기예보 (TMP) | ℃ | 1시간 기온 |
| 체감온도 | 기상청 생활기상지수 | ℃ | 실제 느낌 |
| 지면 온도 | 기온 기반 추정 | ℃ | 발바닥 영향 |
| 습도 | 기상청 (REH) | % | 열사병 영향 |
| 풍속 | 기상청 (WSD) | m/s | 소형견 영향 |
| 강수 형태 | 기상청 (PTY) | 코드 | 비/눈/없음 |
| 강수 확률 | 기상청 (POP) | % | 우산 필요 여부 |
| 자외선 지수 | 기상청 생활기상지수 | 등급 | 피부 영향 |
| 미세먼지 | 에어코리아 (PM10) | μg/m³ | 호흡기 |
| 초미세먼지 | 에어코리아 (PM2.5) | μg/m³ | 호흡기 |

### 2. 반려견 변수

| 변수 | 출처 | 설명 |
| --- | --- | --- |
| 크기 | 견종 마스터 + 체중 | SMALL / MEDIUM / LARGE |
| 털 길이 | 사용자 입력 | LONG / SHORT / MEDIUM |
| 더위 민감도 | 견종 마스터 (1~5) | 견종별 더위 취약도 |
| 추위 민감도 | 견종 마스터 (1~5) | 견종별 추위 취약도 |
| 단두종 여부 | 견종 마스터 | 퍼그·불독 등 |
| 나이 | 생년월일 계산 | YOUNG / ADULT / SENIOR |
| 건강 이슈 | 사용자 입력 | 관절·심장 등 |

## 🌡️ 지면(노면) 온도 추정 — 발바닥 화상 룰 입력 (v1.4)

> 발바닥 화상은 개가 실제로 밟는 **햇볕에 달궈진 아스팔트** 온도가 좌우한다.
> 그런데 수집되는 `ground_temperature` 는 **ASOS 측정 맨땅(TS)** 온도라 아스팔트보다
> 낮게 읽혀(잔디·흙) 화상 위험을 **과소평가**한다. 그래서 지면 화상 룰은 측정값 대신
> **기온 + 일사량(자외선 프록시)으로 추정한 노면온도**를 입력으로 쓴다.
> (구현: [`ai/rules/walk_risk.py`](../ai/rules/walk_risk.py) `estimate_asphalt_temp()`)

**추정 공식**

```
추정 노면온도 = 기온 + 일사계수 × 2.0 × max(0, 기온 − 20)
최종 입력     = max(추정 노면온도, 측정 지면온도)   # 측정값이 더 높으면 그 값(보수적)
```

**일사계수 (자외선지수 프록시, 강수 중엔 0.1)**

| 자외선지수 | 0~2 | 3~5 | 6~7 | 8+ | 강수 중 |
| --- | --- | --- | --- | --- | --- |
| 일사계수 | 0.15 | 0.6 | 0.85 | 1.0 | 0.1 |

**full-sun(자외선 8+) 기준 추정 노면온도** — docs 기존 근사표와 정합

| 기온 (℃) | 추정 노면온도 (아스팔트) |
| --- | --- |
| 25 | 35 |
| 30 | 50 |
| 35 | 65 ⚠️ |

> 🐾 **위험 기준**: 사람 손등을 7초 이상 댈 수 없는 50℃ 이상이면 발바닥 화상 위험
> 예) 기온 27℃·자외선 9(맑음) → 추정 노면 약 41℃ → `GROUND_TEMP_HIGH`(주의).
> 같은 27℃라도 흐림(자외선 2) → 추정 약 31℃ → 미발화(과잉 경보 방지).

### 감점 규칙 (v1) — 구현 기준

> 🔷 **이 표는 코드와 동기화됩니다**: 실제 구현은 [`ai/rules/walk_risk.py`](../ai/rules/walk_risk.py)의 `RULES` 리스트가 source of truth.
> 가중치 조정 시 코드와 이 표를 함께 수정하세요.

| 코드 | 조건 | 감점 | 사유 |
| --- | --- | --- | --- |
| `GROUND_TEMP_SEVERE` | 추정 노면온도 ≥ 50℃ | -40 | 발바닥 화상 위험 |
| `GROUND_TEMP_HIGH` | 추정 노면온도 40~50℃ | -20 | 짧은 산책 권장 |
| `FEELS_HOT` | 체감온도 ≥ 33℃ | -20 | 고온 |
| `BRACHY_HEAT` | 단두종 + 기온 ≥ 28℃ | -25 | 호흡곤란 위험 |
| `LOW_HEAT_TOLERANCE` | 더위내성 ≤ 2 + 기온 ≥ 28℃ | -15 | 더위 취약 견종 |
| `LONG_COAT_HEAT` | 장모 + 기온 ≥ 28℃ | -10 | 장모종 더위 |
| `HUMID_HEAT` | 습도 ≥ 70% + 기온 ≥ 28℃ | -10 | 열사병 위험 |
| `FEELS_COLD` | 체감온도 ≤ -5℃ | -20 | 저온 |
| `LOW_COLD_TOLERANCE` | 추위내성 ≤ 2 + 기온 ≤ 0℃ | -15 | 추위 취약 견종 |
| `SMALL_SHORT_COLD` | 소형 + 단모 + 기온 ≤ 5℃ | -10 | 옷 착용 권장 |
| `PM_VERY_BAD` | PM10 ≥ 151 or PM2.5 ≥ 76 | -30 | 미세먼지 매우 나쁨 |
| `PM_BAD` | PM10 81~150 or PM2.5 36~75 | -15 | 미세먼지 나쁨 |
| `SNOW` | 강수형태 = 눈/비눈 | -15 | 미끄럼·동상 |
| `RAIN` | 강수형태 = 비 | -10 | 우산 챙기기 |
| `SENIOR_EXTREME` | 8세+ & (기온 ≥ 28℃ or ≤ 0℃) | -10 | 노령견 주의 |
| `STRONG_WIND` | 풍속 ≥ 9 m/s | -10 | 강풍 |
| `UV_VERY_HIGH` | 자외선 지수 ≥ 8 | -15 | 자외선 매우 강함 (v1.2) |
| `UV_HIGH` | 자외선 지수 6~7 | -8 | 자외선 강함 (v1.2) |

> 💡 **내열/내한 내성**(heat/cold_tolerance)은 `dog_breeds` 마스터의 1~5 값. 값이 작을수록 취약.
> 단두종 여부(`is_brachycephalic`)도 `dog_breeds`에서 가져옴.

## 🚦 등급 산정 (코드 동기화)

`walk_risk.py`의 `_score_to_level()` 기준 **3단계**:

| 점수 범위 | 등급 | 색상 | 안내 |
| --- | --- | --- | --- |
| 70 ~ 100 | 안전 | 🟢 초록 | 산책하기 좋은 날씨입니다 |
| 40 ~ 69 | 주의 | 🟡 노랑 | 짧은 산책만 권장합니다 |
| 0 ~ 39 | 위험 | 🔴 빨강 | 산책을 피해주세요 |

> 💡 프론트에서 더 세분화한 안내 문구(매우 안전/양호 등)를 보여주고 싶으면, 등급은 3단계로 유지하되 점수 구간별 메시지를 UI에서 분기하세요.

## ⏰ 추천 시간대 산정

### 알고리즘

```
1. 오늘 시간별 예보 데이터 (3시간 단위) 조회
2. 각 시간대별로 위험도 점수 계산
3. 점수가 가장 높은 연속 2~3시간대 추출
4. 시간 범위 반환 (예: "18:00 ~ 20:00")
```

### 시간대 분류

| 시간대 | 범위 |
| --- | --- |
| 새벽 | 04:00 ~ 06:00 |
| 아침 | 06:00 ~ 09:00 |
| 오전 | 09:00 ~ 12:00 |
| 점심 | 12:00 ~ 14:00 |
| 오후 | 14:00 ~ 17:00 |
| 저녁 | 17:00 ~ 20:00 |
| 밤 | 20:00 ~ 23:00 |

### 일반적 추천 우선순위

- **여름**: 새벽 > 저녁 > 밤 > 아침 (낮 회피)
- **겨울**: 점심 > 오후 > 오전 (추위 회피)
- **봄/가을**: 거의 모든 시간대 양호

## 🧪 예시 시나리오

### 시나리오 1: 한여름 오후 2시, 말티즈 (코코 · 페르소나 1)

**입력**
- 견종: 말티즈 (소형, 장모, 더위 민감도 4)
- 날씨: 기온 32℃, 체감 35℃, 습도 75%, 맑음
- 추정 지면 온도: 55℃
- 미세먼지: 보통 (PM10=50)

**계산**
- 체감 33℃ 이상: **-20**
- 단두종 아님: -0
- 더위 민감도 4 + 체감 28℃ 이상: **-10**
- 장모종 + 더위: **-5**
- 지면 50℃ 이상: **-20**
- 소형견 + 지면 40℃ 이상: **-5**
- 습도 70%+기온 30℃+: **-10**

**총 감점**: -70
**점수**: 30 → 🔴 **위험**

**사유**:
- 기온이 너무 높아요
- 지면 온도가 높아 발바닥 화상 위험이 있어요
- 장모종에게 다소 더운 날씨예요
- 습도가 높아 열사병 위험이 있어요

**추천 시간대**: 19:00 ~ 21:00 (저녁)

### 시나리오 2: 봄 저녁 7시, 골든리트리버 (찹츄 · 페르소나 3)

**입력**
- 견종: 골든리트리버 (대형, 장모/이중모, 더위 민감도 3)

## 🛠️ 구현 방향 (Python FastAPI)

### 입력 스키마
```python
class RiskInput(BaseModel):
    dog: DogInfo
    weather: WeatherInfo
    measured_at: datetime

class DogInfo(BaseModel):
    breed: str
    size: str  # SMALL / MEDIUM / LARGE
    coat_type: str  # LONG / SHORT / MEDIUM
    age_years: int
    weight: float
    is_brachycephalic: bool
    heat_sensitivity: int  # 1~5
    cold_sensitivity: int  # 1~5
    health_issues: list[str]

class WeatherInfo(BaseModel):
    temperature: float
    feels_like: float
    humidity: int
    wind_speed: float
    precipitation_type: str  # NONE / RAIN / SNOW
    precipitation_prob: int
    uv_index: int
    pm10: int
    pm25: int
    estimated_ground_temp: float
```

### 출력 스키마
```python
class RiskOutput(BaseModel):
    score: int  # 0~100
    level: str  # SAFE / CAUTION / DANGER
    reasons: list[Reason]
    recommended_time: TimeRange
    supplies: list[str]

class Reason(BaseModel):
    code: str
    message: str
    severity: int  # 1~3
```
