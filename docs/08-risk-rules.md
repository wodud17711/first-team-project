# 08. 산책 위험도 룰베이스

본 서비스의 핵심 AI 기능인 **산책 위험도 측정 룰베이스 모델** 명세입니다.

> 💡 초기 버전(v1)은 규칙 기반(Rule-based)으로 시작하고, 데이터가 축적되면 ML 모델로 확장 예정입니다.

---

## 🎯 목표

다음을 종합하여 **0~100점의 산책 위험도 점수**를 산출합니다:

1. **날씨 데이터** (기상청, 에어코리아)
2. **반려견 특성** (견종, 나이, 체중, 털 길이, 건강상태)
3. **시간대 정보** (오전/오후/저녁/심야)

출력:
- 점수 (0~100)
- 등급 (안전 / 주의 / 위험)
- 위험 사유 리스트
- 추천 시간대

---

## 📊 위험 요소 정의

### 1. 날씨 변수

| 변수 | 출처 | 단위 | 설명 |
| --- | --- | --- | --- |
| 기온 | 기상청 단기예보 (TMP) | ℃ | 1시간 기온 |
| 체감온도 | 기상청 생활기상지수 | ℃ | 실제 느낌 |
| 지면 온도 | 기온 기반 추정 | ℃ | 발바닥 영향 |
| 습도 | 기상청 (REH) | % | 열사병 영향 |
| 풍속 | 기상청 (WSD) | m/s | 소형견 영향 |
| 강수 형태 | 기상청 (PTY) | 코드 | 비/눈/없음 |
| 강수 확률 | 기상청 (POP) | % | 우산 필요 여부 |
| 자외선 지수 | 기상청 생활기상지수 | 등급 | 피부 영향 |
| 미세먼지 | 에어코리아 (PM10) | μg/m³ | 호흡기 |
| 초미세먼지 | 에어코리아 (PM2.5) | μg/m³ | 호흡기 |

### 2. 반려견 변수

| 변수 | 출처 | 설명 |
| --- | --- | --- |
| 크기 | 견종 마스터 + 체중 | SMALL / MEDIUM / LARGE |
| 털 길이 | 사용자 입력 | LONG / SHORT / MEDIUM |
| 더위 민감도 | 견종 마스터 (1~5) | 견종별 더위 취약도 |
| 추위 민감도 | 견종 마스터 (1~5) | 견종별 추위 취약도 |
| 단두종 여부 | 견종 마스터 | 퍼그·불독 등 |
| 나이 | 생년월일 계산 | YOUNG / ADULT / SENIOR |
| 건강 이슈 | 사용자 입력 | 관절·심장 등 |

## 🌡️ 지면 온도 추정 공식

> 지면 온도는 기온보다 훨씬 높을 수 있어 발바닥 화상 위험을 직접 영향

**추정 공식 (실측 데이터 기반 근사)**

| 기온 (℃) | 햇볕 노출 시 추정 지면 온도 (아스팔트) |
| --- | --- |
| 25 | 약 35~40 |
| 30 | 약 50~55 |
| 32 | 약 60 |
| 35 | 약 65 이상 ⚠️ |

> 🐾 **위험 기준**: 사람 손등을 7초 이상 댈 수 없는 50℃ 이상이면 발바닥 화상 위험

**보정 변수**
- 흐림: -10℃
- 그늘: -15℃
- 비온 직후: -5℃

## 🎯 점수 산출 공식

### 기본 구조

```
최종 점수 = 100 - Σ(감점 요소)
```

### 감점 규칙 (v1)

#### 🌡️ 기온 관련

| 조건 | 감점 | 비고 |
| --- | --- | --- |
| 체감온도 ≥ 33℃ | -20 | 폭염 |
| 체감온도 ≥ 30℃ | -15 | 더위 |
| 체감온도 ≥ 28℃ | -10 | 약간 더위 |
| 체감온도 ≤ -5℃ | -20 | 한파 |
| 체감온도 ≤ 0℃ | -15 | 강추위 |
| 체감온도 ≤ 5℃ | -10 | 추위 |

**견종 가중치 적용**
```
if 단두종 and 체감온도 ≥ 28℃:
    감점 += 15  # 단두종은 더위에 매우 취약
if 더위민감도 ≥ 4 and 체감온도 ≥ 28℃:
    감점 += 10
if 단모종 and 체감온도 ≤ 5℃:
    감점 += 10
if 추위민감도 ≥ 4 and 체감온도 ≤ 5℃:
    감점 += 10
```

#### 🔥 지면 온도

| 조건 | 감점 | 비고 |
| --- | --- | --- |
| 지면 온도 ≥ 60℃ | -25 | 즉시 화상 위험 |
| 지면 온도 ≥ 50℃ | -20 | 화상 위험 |
| 지면 온도 ≥ 40℃ | -10 | 주의 |

**소형견 가중치** (지면에 가까움)
```
if 크기 == SMALL and 지면온도 ≥ 40℃:
    감점 += 5
```

#### 💧 습도

| 조건 | 감점 | 비고 |
| --- | --- | --- |
| 습도 ≥ 80% and 기온 ≥ 28℃ | -10 | 열사병 위험 |
| 습도 ≥ 70% and 기온 ≥ 30℃ | -10 | |

#### 💨 풍속

| 조건 | 감점 | 비고 |
| --- | --- | --- |
| 풍속 ≥ 10 m/s | -15 | 강풍 |
| 풍속 ≥ 7 m/s and 소형견 | -10 | 소형견 위험 |

#### ☔ 강수

| 조건 | 감점 | 비고 |
| --- | --- | --- |
| 강수 형태 = 비/소나기 | -15 | 산책 어려움 |
| 강수 형태 = 눈 | -10 | |
| 강수 확률 ≥ 70% | -10 | 도중 비 가능성 |

#### 🌫️ 미세먼지

| 조건 | 감점 | 비고 |
| --- | --- | --- |
| PM10 ≥ 150 (매우 나쁨) | -25 | 호흡기 위험 |
| PM10 ≥ 80 (나쁨) | -15 | |
| PM2.5 ≥ 75 (매우 나쁨) | -25 | |
| PM2.5 ≥ 35 (나쁨) | -15 | |

> 두 항목 동시 적용 시 더 큰 감점만 적용

#### ☀️ 자외선

| 조건 | 감점 | 비고 |
| --- | --- | --- |
| 자외선 = 매우 높음 | -5 | |
| 자외선 = 위험 | -10 | |

#### 👴 나이 / 건강

| 조건 | 감점 | 비고 |
| --- | --- | --- |
| 노견 (8세 이상) and 극한 날씨 | -10 | |
| 어린 강아지 (1세 미만) and 극한 날씨 | -10 | |
| 건강 이슈 있음 and 극한 날씨 | -15 | 사용자 입력 기반 |

## 🚦 등급 산정

| 점수 범위 | 등급 | 색상 | 안내 |
| --- | --- | --- | --- |
| 90 ~ 100 | 매우 안전 | 🟢 진한 초록 | 산책하기 완벽한 날씨예요! |
| 75 ~ 89 | 안전 | 🟢 초록 | 산책하기 좋은 날씨입니다 |
| 60 ~ 74 | 양호 | 🟡 노랑 | 가능하지만 주의가 필요해요 |
| 40 ~ 59 | 주의 | 🟠 주황 | 짧은 산책만 권장합니다 |
| 0 ~ 39 | 위험 | 🔴 빨강 | 산책을 피해주세요 |

## ⏰ 추천 시간대 산정

### 알고리즘

```
1. 오늘 시간별 예보 데이터 (3시간 단위) 조회
2. 각 시간대별로 위험도 점수 계산
3. 점수가 가장 높은 연속 2~3시간대 추출
4. 시간 범위 반환 (예: "18:00 ~ 20:00")
```

### 시간대 분류

| 시간대 | 범위 |
| --- | --- |
| 새벽 | 04:00 ~ 06:00 |
| 아침 | 06:00 ~ 09:00 |
| 오전 | 09:00 ~ 12:00 |
| 점심 | 12:00 ~ 14:00 |
| 오후 | 14:00 ~ 17:00 |
| 저녁 | 17:00 ~ 20:00 |
| 밤 | 20:00 ~ 23:00 |

### 일반적 추천 우선순위

- **여름**: 새벽 > 저녁 > 밤 > 아침 (낮 회피)
- **겨울**: 점심 > 오후 > 오전 (추위 회피)
- **봄/가을**: 거의 모든 시간대 양호

## 🧪 예시 시나리오

### 시나리오 1: 한여름 오후 2시, 포메라니안

**입력**
- 견종: 포메라니안 (소형, 장모, 더위 민감도 4)
- 날씨: 기온 32℃, 체감 35℃, 습도 75%, 맑음
- 추정 지면 온도: 55℃
- 미세먼지: 보통 (PM10=50)

**계산**
- 체감 33℃ 이상: **-20**
- 단두종 아님: -0
- 더위 민감도 4 + 체감 28℃ 이상: **-10**
- 장모종 + 더위: **-5**
- 지면 50℃ 이상: **-20**
- 소형견 + 지면 40℃ 이상: **-5**
- 습도 70%+기온 30℃+: **-10**

**총 감점**: -70
**점수**: 30 → 🔴 **위험**

**사유**:
- 기온이 너무 높아요
- 지면 온도가 높아 발바닥 화상 위험이 있어요
- 장모종에게 다소 더운 날씨예요
- 습도가 높아 열사병 위험이 있어요

**추천 시간대**: 19:00 ~ 21:00 (저녁)

---

### 시나리오 2: 봄 저녁 7시, 보더콜리

**입력**
- 견종: 보더콜리 (대형, 중간 털, 더위 민감도 2)
- 날씨: 기온 20℃, 체감 19℃, 습도 50%, 맑음
- 미세먼지: 좋음

**계산**
- 모든 감점 조건 해당 없음

**총 감점**: 0
**점수**: 100 → 🟢 **매우 안전**

**추천 시간대**: 거의 모든 시간대 가능

## 🛠️ 구현 방향 (Python FastAPI)

### 입력 스키마
```python
class RiskInput(BaseModel):
    dog: DogInfo
    weather: WeatherInfo
    measured_at: datetime

class DogInfo(BaseModel):
    breed: str
    size: str  # SMALL / MEDIUM / LARGE
    coat_type: str  # LONG / SHORT / MEDIUM
    age_years: int
    weight: float
    is_brachycephalic: bool
    heat_sensitivity: int  # 1~5
    cold_sensitivity: int  # 1~5
    health_issues: list[str]

class WeatherInfo(BaseModel):
    temperature: float
    feels_like: float
    humidity: int
    wind_speed: float
    precipitation_type: str  # NONE / RAIN / SNOW
    precipitation_prob: int
    uv_index: int
    pm10: int
    pm25: int
    estimated_ground_temp: float
```

### 출력 스키마
```python
class RiskOutput(BaseModel):
    score: int  # 0~100
    level: str  # SAFE / CAUTION / DANGER
    reasons: list[Reason]
    recommended_time: TimeRange
    supplies: list[str]

class Reason(BaseModel):
    code: str
    message: str
    severity: int  # 1~3
```

## 📈 향후 개선 방향

### v2 (데이터 축적 후)
