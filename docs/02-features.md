### 2. 반려견 프로필 관리

| ID | 기능 | 설명 |
| --- | --- | --- |
| F-DOG-01 | 반려견 등록 | 견종·나이·체중·털 길이·활동량·건강상태 입력 |
| F-DOG-02 | 반려견 목록 조회 | 한 사용자가 여러 마리 등록 가능 |
| F-DOG-03 | 반려견 상세 조회 | 개별 반려견 정보 |
| F-DOG-04 | 반려견 정보 수정 | 등록한 정보 수정 |
| F-DOG-05 | 반려견 삭제 | 프로필 삭제 |
| F-DOG-06 | 프로필 사진 업로드 | 이미지 업로드 (S3 또는 로컬) |

**입력 필드**
- 이름 (필수)
- 견종 (필수, 드롭다운)
- 생년월일 또는 나이
- 체중 (kg)
- 털 길이 (장모/단모/중간)
- 활동량 (낮음/보통/높음)
- 건강 특이사항 (선택, 텍스트)
- 산책 선호 시간대

### 3. AI 산책 위험도 측정

| ID | 기능 | 설명 |
| --- | --- | --- |
| F-RISK-01 | 오늘의 산책 점수 | 0~100점 + 등급(안전/주의/위험) |
| F-RISK-02 | 위험 사유 안내 | "지면 온도 높음", "단모종에 추운 날씨" 등 |
| F-RISK-03 | 최적 시간대 추천 | 시간별 예보 기반 안전 시간대 |
| F-RISK-04 | 준비물 추천 | 날씨에 따른 우산, 패딩, 물 등 안내 |

**처리 흐름**
1. 사용자 위치(위경도) + 반려견 정보 조회
2. 위경도 → 기상청 격자 좌표(nx, ny) 변환
3. 기상청 단기예보 + 에어코리아 미세먼지 데이터 조회
4. 룰베이스 모델로 위험도 계산 ([08. 산책 위험도 룰베이스](./08-risk-rules.md) 참고)
5. 결과 반환

## ⏳ 향후 확장 기능 (2차)

### 산책로 추천 시스템
- 위치 기반 주변 산책로 추천
- 산책로 난이도 (초보/중수/고수)
- 사용자 리뷰 및 평점
- 핫플레이스 표시

### 러닝 모드
- 특정 코스 완주 시간 측정
- 견주 간 기록 비교 / 랭킹

### 게이미피케이션
- 산책 미션 (예: 5분 뛰기, 쓰레기 줍기)
- 배지 / 업적 시스템
- 산책 횟수·시간 기반 랭킹

### AI 견종 분류
- 사진 업로드 → 견종 자동 인식
- Stanford Dogs Dataset 활용

### 견주 유형 분석
- 산책 패턴 분석하여 "○○형 견주" 진단

### OpenAI 기반 Q&A
- 견종별 궁금증 해결 챗봇
