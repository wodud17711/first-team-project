| ID | 기능 | 설명 |
| --- | --- | --- |
| F-DOG-01 | 반려견 등록 | 견종·나이·체중·털 길이·활동량·건강상태 입력 |
| F-DOG-02 | 반려견 목록 조회 | 한 사용자가 여러 마리 등록 가능 |

**입력 필드**

### 3. AI 산책 위험도 측정

| ID | 기능 | 설명 |
| --- | --- | --- |
| F-RISK-01 | 오늘의 산책 점수 | 0~100점 + 등급(안전/주의/위험) |
| F-RISK-02 | 위험 사유 안내 | "지면 온도 높음", "단모종에 추운 날씨" 등 |
| F-RISK-03 | 최적 시간대 추천 | 시간별 예보 기반 안전 시간대 |
| F-RISK-04 | 준비물 추천 | 날씨에 따른 우산, 패딩, 물 등 안내 |

**처리 흐름**
1. 사용자 위치(위경도) + 반려견 정보 조회
2. 위경도 → 기상청 격자 좌표(nx, ny) 변환
3. 기상청 단기예보 + 에어코리아 미세먼지 데이터 조회
4. 룰베이스 모델로 위험도 계산 ([08. 산책 위험도 룰베이스](./08-risk-rules.md) 참고)
5. 결과 반환

#### 🏷 서브태그 동작 (사료·간식, 병원·영양제만 해당)

**글 작성 시**: 카테고리 선택 후 서브태그 라디오 버튼으로 선택

```
카테고리: 사료·간식
서브태그: ⚪ 사료    ⚪ 간식  ← 둘 중 하나 필수 선택
```

**글 목록 표시 시**: `[서브태그] 제목` 형태

```
[사료] 코코한테 좋은 사료 추천해주세요
[간식] 다이어트 간식 후기 모음
[사료] 알러지 있는 강아지 사료 알려주세요
```

**필터 버튼**: 카테고리 페이지 상단에 `[전체] [사료] [간식]` 토글로 제공

> 💡 서브태그는 `posts.sub_tag VARCHAR(20)` 컬럼에 저장. 사용 가능한 서브태그는 `categories.sub_tags JSON`에서 카테고리별로 정의.

## ⏳ 향후 확장 기능 (Phase 2)

### 1:1 채팅 (견주 간 직접 소통)
- **배경**: 게시판만으로 견종별 정보 교환에 한계 (답글 안 달리거나 느림)
- 사용자 간 1:1 메시지
- 읽음/안읽음 표시
- 차단·신고 기능
- **MVP에서 보류 이유**: WebSocket 인프라 + 신고·차단·푸시까지 약 2주 작업 추정
- **MVP에서의 보완책** (아래 "MVP 채팅 대안" 참고)

### 산책로 추천 시스템 (Phase 2)
- 위치 기반 주변 산책로 추천
- 산책로 난이도 (초보/중수/고수)
- 사용자 리뷰 및 평점
- 핫플레이스 표시

### 실시간 GPS 트래킹 (Phase 3 - 모바일 앱)
- **MVP는 웹앱**이라 실시간 GPS는 부적합 (백그라운드 추적 제약, 배터리)
- 모바일 앱 출시 시점에 도입 예정
- MVP에서는 산책 시작/종료 시각만 기록 (수동)

### 러닝 모드 (Phase 2)
- 특정 코스 완주 시간 측정
- 견주 간 기록 비교 / 랭킹

### 게이미피케이션 (Phase 2)
- 산책 미션 (예: 5분 뛰기, 쓰레기 줍기)
- 배지 / 업적 시스템
- 산책 횟수·시간 기반 랭킹

### AI 견종 분류 (Phase 2)
- 사진 업로드 → 견종 자동 인식
- Stanford Dogs Dataset 활용

### 견주 유형 분석 (Phase 2)
- 산책 패턴 분석하여 "○○형 견주" 진단

### OpenAI 기반 Q&A (Phase 2)
- 견종별 궁금증 해결 챗봇

## 💬 MVP 채팅 대안 (1:1 채팅 도입 전 대체 수단)

1:1 채팅은 Phase 2로 미루지만, **답글 안 달리는 문제**는 MVP에서도 다음으로 보완:

| 대안 | 효과 | 구현 비용 |
| --- | --- | --- |
| **댓글 알림 강화** | 내 글에 댓글 달리면 알림 → 빠른 답변 유도 | 작음 (이미 `notifications` 테이블 존재) |
| **댓글 내 @멘션** | "@닉네임" 입력 시 해당 사용자에게 알림 | 중간 |
| **견종 자동 매칭 알림** | 글 작성 시 동일 견종 견주에게 알림 | 중간 |
| **"경험자" 배지 표시** | 같은 견종 5년+ 견주가 답하면 우대 표시 | 작음 |

이걸로도 채팅 효과의 ~70%를 낼 수 있고, **유저 100명+ 모이면** 그때 1:1 채팅 도입 검토.
