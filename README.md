# 🐕 반려견 산책 라이프 플랫폼

> 기상청 날씨 데이터와 반려견 정보를 AI로 분석하여 **산책 위험도 진단**과 **최적 산책시간 추천**을 제공하고,
> 견주 간 정보 교류가 가능한 **커뮤니티**를 통합한 올인원 반려견 라이프 플랫폼

---

## 📌 서비스 개요

기상청 날씨 데이터와 반려견의 견종·나이·건강상태·활동성 등을 AI로 분석하여 산책 위험도 진단과 최적 산책시간 추천을 제공하고, 견주 간 정보 교류가 가능한 커뮤니티 기능을 통합한 반려견 산책 라이프 플랫폼입니다.

## 💡 기획 배경

견주들은 매일 다음과 같은 고민을 합니다.

- "오늘 산책해도 괜찮은 날씨인가?"
- "지면이 너무 뜨겁진 않은가?"
- "우리 강아지에게 오늘 날씨가 안전한가?"

특히 **견종·나이·건강상태에 따라 동일한 날씨라도 산책 위험도가 크게 달라지지만**, 이를 종합적으로 판단해주는 서비스가 부재합니다. 또한 초보 견주가 사료, 간식, 병원 등의 정보를 얻을 수 있는 통합 플랫폼도 부족한 상황입니다.

이에 **날씨 + 반려견 데이터 기반 맞춤형 산책 가이드 + 커뮤니티**를 결합한 서비스를 기획하였습니다.

## 🎯 타겟층

| 타입 | 설명 |
| --- | --- |
| 🐶 초보 견주 | 강아지에 대한 지식이 부족한 사용자 |
| 🚶 일반 견주 | 매일 산책 적합성을 판단하기 어려운 사용자 |
| 🏃 액티브 견주 | 반려견과 함께 러닝·운동을 즐기는 사용자 |

## 🔧 주요 기능

### ① 회원가입 및 반려견 프로필 등록
- 견종, 나이, 체중, 털 길이(장모/단모), 활동량, 건강상태, 산책 선호 시간 입력

### ② AI 산책 위험도 측정 및 추천
- 오늘의 산책 점수 및 사유 안내
  - 예: "지면이 뜨거워 발바닥 화상 위험"
  - 예: "해당 견종은 오늘 날씨에 취약"
- 최적 산책시간 추천
- 산책 시작/완료 기능 및 완료 후 사용자 피드백 수집을 통한 AI 개선

### ③ 산책 기록 및 통계
- 주간·월간 산책 횟수와 시간 통계
- 날씨별 산책 데이터
- 일별 산책 캘린더 제공

### ④ 위치 기반 산책길 추천
- 거주지 주변 공원·그늘 루트 등 맞춤 추천
- 견주 리뷰 시스템 (계절별 추천도 등)
- 핫플레이스 표시 및 난이도(초보/중수/고수) 구분

### ⑤ 러닝 모드
- 특정 산책로 완주 시간 측정
- 사용자 간 경쟁 기능

### ⑥ 게이미피케이션
- 산책 중 미션 부여 (쓰레기 줍기, 물 마시기 등)
- 산책 완료 시 배지·업적 지급
- 산책 횟수·시간 기반 랭킹 시스템

### ⑦ 견주 커뮤니티
- 카테고리별 게시판 운영
  - 사료, 간식, 병원 후기
  - 산책로 후기
  - 반려견 자랑
  - 동반 산책 모집

### ⑧ 산책 기록 페이지
- 반려견과의 추억 기록
- 산책 중 행동·상태 등 기록 가능

### ⑨ 날씨 기반 준비물 추천
- 기본 준비물 안내
- 강수 예보 시 우산 챙기기 등 상황별 알림

### ⑩ OpenAI 기반 Q&A 공간
- 견종별 궁금증을 해소할 수 있는 AI 질문 공간

### ⑪ 견주 유형 분석
- 산책 빈도·시간·시간대 분석을 통한 견주 유형 진단
  - 예: "○○형 견주"

## 🤖 AI 모델 개발 계획

### ① 산책 위험도 분류 모델

**입력 데이터 (기상청)**
- 기온, 지면온도, 습도, 풍속, 체감온도, 미세먼지

**입력 데이터 (반려견)**
- 견종, 나이, 체중, 털 길이 등 (Kaggle 데이터 활용)

**출력**
- `안전` / `주의` / `위험` 3단계 분류

### ② 견종 이미지 분류 모델 (옵션)
- 견종을 모르는 견주를 위한 사진 기반 견종 식별 기능

## ⭐ 차별화 포인트

단순 날씨 앱이나 산책 기록 앱과 달리,

> **AI 기반 개체 맞춤형 위험도 진단 + 위치 기반 산책로 추천 + 커뮤니티 + 게이미피케이션**

을 통합한 **올인원 반려견 라이프 플랫폼**이라는 점에서 차별성을 가집니다.
